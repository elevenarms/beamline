# Optical calculator: logic gates from polarization optics

**How it works.** Each input bit is a half-wave plate: fast axis 0° = bit 0 (H stays H), 45° = bit 1 (H flips to V). A PBS transmits H and reflects V, so a chain of plates and PBSs steers the single laser "rail" onto exactly one path for each input combination. A photodiode reads an output as 1 when it gets more than 20% of the laser power (dark outputs read exactly 0). Plate B (and CIN in the full adder) is mounted at 45° where the two A-rails cross, so one plate acts on both paths. Spare PBSs merge disjoint paths onto a single output detector (OR).

**Designs** (`backend/examples/`): `optical_nand.json` (NAND + AND outputs), `optical_half_adder.json` (SUM = A XOR B, CARRY = A AND B; loads as **1 + 1 = 10**), `optical_full_adder.json` (A + B + CIN; loads as **1 + 1 + 1 = 11**). Print the truth tables with `cd backend && uv run python -m logic examples/optical_half_adder.json`.

**Live demo.** Load "optical_half_adder" in the web app. It opens with A = B = 1: the CARRY PD is lit (9.5 mW in the inspector) and SUM is dark, so it reads 1 + 1 = 10. Click plate **B**, set Fast axis to 0°, and the beam re-routes through PBS 1 to the **SUM PD** (1 + 0 = 01). Set **A** to 0° too and all the light ends in the 0 + 0 dump. Dragging the slider through in-between angles splits the power between the outputs, and the design still passes verify at every angle. The NAND gate works the same way: its NAND PD stays lit until both A and B are at 45°.

**Honest caveat.** This is linear "directed logic". The inputs are waveplate settings, not light, and the result comes out as which detector is lit. A real optical computer also needs cascadability (an output beam driving the next gate's input) and gain, and both of those require nonlinearity or optoelectronics. Fan-in costs 3 dB per 50:50 merge (see the full adder), because linear optics cannot losslessly merge two beams into one mode. Directed logic is still a legitimate computing paradigm (as in the directed-logic papers on integrated photonics), and the bench physics shown here is real.
